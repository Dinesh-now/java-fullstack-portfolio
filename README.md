# Dinesh K - Portfolio

React + Vite + Tailwind portfolio.

## Run

```bash
npm install
npm run dev
```

## Update content

All text, projects, skills, and links are in `src/data.js`.

- Add the CSES repository / live links in the `projects` array (`github`, `live`).
- Replace `public/resume/Dinesh_K_Resume.pdf` with your latest resume PDF (keep the same file name).
